# 개인정보 처리 체크리스트

개인정보처리방침 URL: 웹 배포 주소의 `/privacy` (예: `https://<netlify-site>/privacy`). 앱 내 `프로필 → 개인정보처리방침`에도 같은 내용이 있습니다(ko/en).

## 앱이 처리하는 데이터

| 데이터 | 언제 | 저장 위치 | 목적 | 비고 |
| --- | --- | --- | --- | --- |
| FMC 세션, 비행계획, 레슨/시나리오 기록 | 항상 | 기기 SQLite | 앱 기능 | 로그인 전에는 기기 밖으로 전송되지 않음 |
| 이메일, 표시 이름, 사용자 ID | 로그인 시 | Firebase Auth | 계정 | Google 로그인 또는 이메일/비밀번호 |
| 세션·시나리오·진도 사본 | 로그인 + 동기화 켬 | Cloud Firestore | 기기 간 동기화 | 사용자 본인만 접근(보안 규칙) |
| 공유한 시나리오 | 사용자가 공유 시 | Cloud Firestore | 공유 | 작성자 표시 이름 포함, 공개 범위 선택 |
| 앱 사용 이벤트 | Analytics 동의 시 | Google Analytics for Firebase | 개선 | 비행계획·공항·경로 등 입력 내용은 수집하지 않음(정제 후 전송) |
| 비정상 종료 로그 | `google-services.json` 포함 빌드 + 동의 시 | Firebase Crashlytics | 안정성 | 기기 모델, OS, 스택 트레이스 |
| 광고 ID | 광고 활성 빌드 + 동의(UMP) 시 | Google AdMob | 광고 | 기본 빌드에는 SDK·AD_ID 권한 없음 |

## 확인 항목

- [ ] 개인정보처리방침 URL이 공개 접근 가능하고 앱 내 문서와 내용이 같다
- [ ] 개인정보처리방침에 수집 항목, 목적, 보관 기간, 제3자(Google/Firebase), 삭제 방법, 연락처(admin@heonhwi.dev)가 있다
- [ ] 앱 내 **계정 삭제**(프로필 → 계정 → 계정 삭제)가 동작하고 Firestore 데이터와 Auth 계정이 삭제된다(클라이언트 처리, 웹 `https://aerofms.netlify.app/account`에서도 가능)
- [ ] 앱 밖에서 삭제를 요청할 수 있는 웹 경로/이메일을 Play Console "데이터 삭제" 항목에 입력했다
- [ ] Analytics·Crashlytics는 설정 → 개인정보에서 끌 수 있다
- [ ] 위치, 연락처, 카메라, 마이크, 저장소 권한을 요청하지 않는다(매니페스트에서 차단)
- [ ] 아동 대상 앱으로 지정하지 않는다(대상 연령 13세 이상 권장)
- [ ] 광고를 켜는 경우: UMP 동의, 광고 ID 선언, 데이터 보안 양식 갱신
