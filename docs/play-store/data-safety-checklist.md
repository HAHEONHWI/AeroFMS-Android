# 데이터 보안(Data safety) 양식 작성 가이드

기본 빌드(광고 비활성, Firebase 설정 포함) 기준입니다. 빌드 구성이 바뀌면 다시 확인하세요.

## 데이터 수집 및 공유

- 데이터를 수집합니까? **예** (로그인·동기화·분석을 사용하는 경우)
- 전송 중 암호화? **예** (Firebase는 HTTPS/TLS 사용)
- 사용자가 데이터 삭제를 요청할 수 있습니까? **예** (앱 내 계정 삭제 + 웹 요청 경로)

| 카테고리 | 항목 | 수집 | 공유 | 필수/선택 | 목적 |
| --- | --- | --- | --- | --- | --- |
| 개인 정보 | 이메일 주소 | 예 | 아니요 | 선택(로그인 시) | 계정 관리 |
| 개인 정보 | 이름(표시 이름) | 예 | 아니요 | 선택 | 계정 관리, 앱 기능(시나리오 작성자 표시) |
| 개인 정보 | 사용자 ID | 예 | 아니요 | 선택 | 계정 관리 |
| 앱 활동 | 앱 상호작용 | 예 | 아니요 | 선택(동의) | 분석 |
| 앱 활동 | 기타 사용자 생성 콘텐츠(시나리오, 세션) | 예 | 아니요 | 선택(동기화) | 앱 기능 |
| 앱 정보 및 성능 | 비정상 종료 로그, 진단 | 예 | 아니요 | 선택(동의) | 분석 |
| 기기 또는 기타 ID | Firebase 설치 ID | 예 | 아니요 | 선택 | 분석 |

수집하지 **않는** 항목: 위치, 연락처, 사진/동영상, 오디오, 파일, 캘린더, 금융 정보, 건강 정보, 웹 탐색 기록, 메시지.

> Google(Firebase)은 Play 정책상 "서비스 제공업체"이므로 위 데이터는 "공유"에 해당하지 않습니다.

## 광고를 켠 빌드에서 추가

| 카테고리 | 항목 | 수집 | 공유 | 목적 |
| --- | --- | --- | --- | --- |
| 기기 또는 기타 ID | 광고 ID | 예 | 예(광고 네트워크) | 광고 |

또한 Play Console → 앱 콘텐츠 → **광고 포함: 예**, **광고 ID 사용 선언**을 갱신합니다.
